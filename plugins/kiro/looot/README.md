# looot power for Kiro

Find, price and run data APIs for SEO, enrichment, email verification and social from one account. Pay per call, no provider keys.

The power adds the looot MCP server (https://api.looot.ai/mcp) and the looot skill. Kiro starts the browser sign-in the first time it connects; no key goes in any file.

Install: Kiro Powers panel, Add Custom Power, Import from GitHub URL, then this folder's URL.
